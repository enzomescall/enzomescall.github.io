QUERO Metrô

  • Live QUERO Transporte app hosted on my Oracle Cloud server under enzom.duckdns.org/quero/.
  • Visualizes rail and metro network data and journey-time scenarios from GeoJSON inputs.
  • Built as a Vite static app deployed behind Caddy.
Open QUEROSource code

Hard Mode Easy Damage

  • Keeps the server on Hard so mechanics like villager conversion and other Hard behavior remain intact.
  • Applies a configurable multiplier to hostile mob damage against players.
  • Includes reload commands and config options for damage multiplier, Hard-only behavior, and ignored entity types.
  • Paper server-side plugin, Java 21, GPL-3.0-or-later.
Open on ModrinthSource

OpenRouter Chat

  • Lets players send single-turn prompts and receive model responses inside game chat.
  • No bundled secrets; operators can manage API keys from config, console, or in-game commands.
  • Configurable model, system prompt, token limit, temperature, timeout, formatting, and permissions.
  • Paper server-side plugin, Java 21, GPL-3.0-or-later.
Open on ModrinthSource

Ecology

  • Live React and Express app hosted on my Oracle Cloud server at enzom.duckdns.org/ecology/.
  • Nature-themed multiplayer card game with lobby creation, invites, simultaneous turn submission, and scoring analytics.
  • Uses email one-time codes for login and a small JSON-backed local database at /var/lib/ecology for persistent game state.
  • Built with TypeScript, React, Vite, Express, and Caddy path routing.
